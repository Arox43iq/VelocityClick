### 💻 ¿Qué hay en este repositorio?
Este repositorio contiene únicamente el **código fuente** del proyecto para que otros desarrolladores puedan ver cómo está construido, inspeccionar el código o proponer mejoras. 

Si eres desarrollador y quieres correrlo localmente en tu computadora:
1. Clona el repositorio:

   git clone [https://github.com/Arox43iq/VelocityClick.git](https://github.com/Arox43iq/VelocityClick.git)

2.Instala las dependencias:

npm install


3.Inicia el servidor de desarrollo:

npm run dev
